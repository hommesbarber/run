HOMMES Run Barber — серверная проверка призового забега

Что включено
index.html — клиент с локальной игрой и отправкой действий серверу.
server.cjs, protocol.cjs, replay.cjs — HTTP-сервер, проверка времени и пересчёт физики.
firestore.rules — версия правил, закрывающая прямую запись очков из браузера.
test.cjs — локальный тест протокола, пересчёта и повторной отправки.

Проверка
Node.js 22 или новее: node test.cjs
Сервер проверяет Firebase ID token при старте, выдаёт случайный идентификатор
забега и seed трассы. Клиент отправляет прыжки, отпускания и подкаты раз в
секунду. Сервер сравнивает номер шага с прошедшим временем и пересчитывает
дистанцию, столкновения и очки из исходного кода той же версии.
Допуск опережения 150 мс, отставания 1250 мс с учётом сети и старта.
Покадровый пересчёт препятствует подмене готового результата. Допуск на сеть
и автоматизация действий по заранее известной трассе остаются ограничениями.

Внедрение на Spark
1. Разместить сервер на одном постоянно доступном Node.js-инстансе с HTTPS
   (поддерживается контейнер из Dockerfile). Он хранит короткие сессии в
   памяти, поэтому масштабирование на несколько инстансов или остановка
   процесса требуют общего хранилища либо маршрутизации по сессии.
2. Подключить Application Default Credentials в настройках хоста для
   сервисной учётной записи с доступом к Firestore проекта hommesgame-9b2dc.
   Файл ключа не должен попадать в GitHub, в клиентский HTML или в этот архив.
   При доступной федерации использовать учётные данные без ключа.
3. Проверить /health и один зачётный забег в отдельной тестовой базе.
   Для теста использовать FIREBASE_PROJECT_ID и GAME_ORIGIN тестовой среды.
4. Указать HTTPS-адрес /ranked в RANKED_URL в index.html. Развернуть клиент
   и сервер из одного и того же исходника. Затем опубликовать firestore.rules
   и проверить запись через сервер и отказ при прямой записи из клиента.
   При пустом адресе клиент допускает тренировку, без записи в рейтинг.
5. Существующие рекорды сохраняются. Они могли быть записаны до серверной
   проверки. Новые рекорды, вычисленные сервером, получают verified=true.

Сервер слушает PORT (по умолчанию 8080). По умолчанию принимает запросы
из https://hommesbarber.github.io. Правила Spark публикуются в Firebase Console,
а веб-клиент на GitHub Pages. Обновление проекта до Blaze не требуется
при использовании отдельного хоста.

При использовании Render Free клиент сначала ждёт готовности /health.
Обратный отсчёт серверного забега начинается только после пробуждения
хоста. Во время ожидания кнопка показывает «ПОДКЛЮЧАЕМСЯ…».
